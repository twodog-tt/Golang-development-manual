# 因子研究与统计验证：收益风险、IC、样本外和过拟合

## 30 秒版（开场）

> 研究从可证伪的假设出发，用当时可用数据生成信号，在时间顺序约束下验证样本外表现。因子相关性、预测准确率和扣除成本后的组合收益是不同指标。每次参数选择都消耗验证信息；反复观察测试集再修改策略，会使它逐渐变成训练集。

## 3 分钟版（精讲深度）

1. **定义实验单位**：市场、标的集合、信号时点、预测期限、成交时点和基准。
2. **按时间隔离**：训练拟合、验证选参、最终测试；重叠标签需额外处理泄漏。
3. **报告完整分布**：收益、回撤、换手、敞口、样本量与成本敏感性，而非只报最佳 Sharpe。

## 10 分钟版（原理 + 图示）

### 数学知识如何落地

| 概念 | 在量化研究中的用途 | 易错点 |
|------|--------------------|--------|
| 条件概率 / 条件期望 | 在已知信息下估计收益与风险 | 用未来已实现事件筛选过去样本 |
| 方差 / 协方差 | 波动、组合风险与相关暴露 | 将相关性当因果，忽略危机期共振 |
| 回归 / 残差 | 控制行业、规模或市场暴露 | 在全样本上拟合后再切训练测试 |
| 假设检验 / 置信区间 | 区分噪声和统计证据 | 忽略相关样本、多重搜索与小样本 |
| 自相关 / 非平稳性 | 评估时间依赖与分布变化 | 随机打散时间序列以制造稳定结果 |

### 指标的明确口径

对含公司行动与现金流口径已统一的总收益价格，可写简单收益 `r_t = P_t / P_(t-1) - 1`。
投资组合有外部入金/出金时，应先定义净值与现金流处理方式，不能直接用余额涨幅作为策略收益。

```text
同频超额收益 e_t = portfolio_return_t - risk_free_return_t
同频 Sharpe 估计 = mean(e_t) / sample_std(e_t)
期末回撤 DD_t = 1 - equity_t / max(equity_0 ... equity_t)
最大回撤 MDD = max(DD_t)
```

用 `sqrt(M)` 年化 Sharpe 要说明每年频数和收益过程假设；自相关、重叠收益与非平稳会影响估计与置信区间。
股票交易日与全天市场不能无说明共用同一个年化系数；波动为零时 Sharpe 不定义。
回撤需说明是否计入未实现损益、费用和资金流。

### 因子 IC 与组合收益

截面因子可在每个调仓时点计算：`IC_t = corr(factor_i,t, forward_return_i,t→t+h)`。
Rank IC 常使用秩相关；必须记录有效样本数、缺失值、并列秩和未来收益区间。
单标的时间序列预测需用对应的时间序列评价，不能直接套用截面排名解释。

| 阶段 | 验证什么 | 仍未证明什么 |
|------|----------|--------------|
| IC / 分组收益 | 信号与未来收益的统计关系 | 组合约束、成交与费用后的收益 |
| 组合构建 | 信号到权重、风险暴露与换手 | 可成交容量与融资/借券可行性 |
| 扣费回测 | 在指定模型下的净收益 | 真实成交与未来市场表现 |
| 仿真 / 小规模验证 | 实际数据、执行和系统偏差 | 更大资金规模或不同市场下的结果 |

### 时间划分与重叠标签

```text
窗口 A：过去训练 → 后续验证 → 再后续测试
窗口 B：向后滚动训练/验证/测试；每次只使用该时点以前可见的数据
最终保留区间：冻结研究流程后只评估一次；继续调参则需重新定义未见数据
```

标准化、缺失填补、特征筛选和模型拟合都只在训练区间估计，再应用到后续数据。
若标签覆盖未来 `h` 个时点，相邻训练/验证样本的标签区间可能重叠，需要按实际信息区间剔除重叠样本（purge），并按实验设计设置隔离区间（embargo）。
scikit-learn `TimeSeriesSplit` 的 `gap` 提供训练尾部样本间隔；它不自动理解不等长标签区间、公告可用时间或所有跨资产泄漏。

### 参数搜索与稳健性

保留全部候选参数、失败实验、切分方案和选择规则。测试数越多，偶然得到漂亮结果的机会越大；不能只保存冠军策略。
检查相邻参数、不同阶段、不同标的与成本压力下的行为，同时保留因研究选择这些检查而产生的选择偏差记录。
经济解释与稳健性可提高可解释程度，仍不能替代独立样本。

## 生产场景

研究平台应保存输入数据快照、特征定义、代码/依赖版本、随机种子、切分边界、成本模型与全部实验结果。
上线后跟踪特征缺失、预测分布、持仓暴露与收益归因；异常时先定位数据或执行变化，再判断是否需要重训练。

## 排查与工具

看到显著提升时，先检查 `available_time`、标签生成、历史成分、标准化范围和成本开关。
再分解收益是否集中于少数事件、低流动性标的或不可实现的做空交易。
对相关收益序列，采用与假设匹配的统计推断或块抽样方案；不要把每个 tick 都当独立样本。

## 架构取舍

简单、可解释的基线便于发现数据与回测错误；复杂模型只有在相同信息集和验证协议下比较才有意义。
长训练窗增加样本但可能混入旧机制；短窗适应变化但估计方差更大，应由预先定义的验证过程选择。

## 深挖问答

1. **为什么不用随机 K 折？** → 时间相关、标签重叠和未来信息会破坏独立同分布直觉，需按信息可用顺序切分。
2. **IC 为正为什么仍亏损？** → 换手、成本、暴露、容量或组合映射可能抵消预测优势。
3. **Sharpe 很高能说明什么？** → 只是在指定样本和口径下的估计，还需样本长度、相关性、尾部与搜索次数信息。
4. **为什么不用全样本均值做标准化？** → 测试区间统计量会进入训练，产生信息泄漏。

## 反模式与事故

- 调参直到测试集收益最好，再称其为未见样本。
- 将缺失价格向前或向后填补后无条件视为可成交报价。
- 删除亏损策略记录，只展示一个最优参数。
- 因子、组合与基准的时间区间、费用和计价货币不一致。
